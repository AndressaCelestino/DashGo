Next.js dashboard scaffold

DashGo

A TypeScript dashboard starter built on Next.js 12, React 18 and Chakra UI, with the application provider and custom design tokens already wired for future interface work.

View repository

Overview

The current app renders a simple Dashgo home page through src/pages/index.tsx. The important foundation lives in _app.tsx, where ChakraProvider wraps the Next app and injects a shared theme from src/styles/theme.ts.

Features

Next.js page structure

Uses the classic src/pages router with a root page and custom app component.

Chakra provider

Wraps every page with Chakra UI so components can share theme values and accessible primitives.

Custom gray palette

Defines gray color tokens from 50 to 900 for a dashboard-oriented visual system.

Global styling

Sets global body background and text colors through the Chakra theme layer.

TypeScript setup

Includes Next, React and Node typings with a TypeScript configuration ready for typed components.

Development scripts

Provides standard dev, build, start and lint package scripts.

Tech Stack

  • Next.js 12
  • React 18
  • TypeScript
  • Chakra UI
  • Emotion
  • Framer Motion

How It Works

Run the app with the package manager scripts, then Next.js loads src/pages/index.tsx. Before rendering that page, src/pages/_app.tsx applies ChakraProvider and the extended theme so new dashboard screens can reuse the same base styling.
